# Wokwi ESP32 Simulation

- Board: ESP32 (simulated).
- Entry button: GPIO 22.
- Exit button: GPIO 18.
- Buttons use INPUT_PULLUP and connect to GND.
- Simulation Wi-Fi: Wokwi-GUEST.

Demo: start simulation, press Entry, inspect response, press Exit, then test exit at zero. Add your actual Wokwi project link if available. Do not claim physical hardware testing.
